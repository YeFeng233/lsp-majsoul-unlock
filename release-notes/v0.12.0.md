# 0.12.0 · 应用内更新、模型导入兼容与界面整理

## 应用内更新与 GitHub 加速

- 更新页支持直接从本仓库 Release 下载对应设备架构的 APK，显示下载进度，并提供取消和失败重试。
- 下载完成后校验包名、版本、文件大小、签名及发布摘要（若提供），点击“安装更新”打开系统安装界面。首次使用会引导开启安装权限，授权返回后继续安装；安装仍需用户确认。
- GitHub 加速设置移到更新页顶部，解锁清单、版本检查和 APK 下载共用所选线路，加速失败后自动尝试直连。已有有效下载包可复用。

## 模型导入与诊断

- 针对 Android 12 上 `.pth` 导入出现 `invalid CEN header (bad signature)` 的反馈，将预校验从 Java `ZipFile` 改为模型加载路径使用的 Rust ZIP/ZIP64 读取器。
- 保留 300 MiB 单文件、600 MiB 解压体积、5000 条目和 4 MiB 元数据限制，以及后续模型结构和推理自检。
- 模型导入新增开始、格式识别、文件复制、验证和完成事件；失败日志记录导入编号、所在阶段、异常信息、耗时和原生状态码，便于从故障包定位问题。
- 日志页新增“清理日志”，可确认清理当前分类或全部日志，包括筛选隐藏的历史记录；清理后刷新列表，新日志继续正常记录。

## 界面布局

- 统一概览、助手、更新页和日志卡片的宽度、圆角、内边距与间距。
- 主要按钮统一宽度和最小高度，并排按钮等宽；窄屏或大字体时自动上下排列，长内容保留自然高度。
- 四麻与三麻模型的共同说明集中显示，长信息调整为可换行布局，日志筛选支持横向滚动。

## 安装与验证说明

- 提供 ARM64 和 Universal 安装包，最低 Android 10，沿用原有签名，可覆盖安装。安装后请完全重启雀魂。
- 新增 ZIP/ZIP64、模型导入日志、日志清理范围、安装包身份与完整性、加速回退和取消行为的验证用例；发布工作流运行原生测试及 Android 模拟器检查。
- Android 12 上用户提供的实际模型文件，以及完整下载、授权、覆盖安装流程，尚未在该用户设备复测。模型支持范围和实验性说明沿用 0.11.0。
