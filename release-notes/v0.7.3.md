# 0.7.3

修复更换角色皮肤后，退出游戏或结束进程再登录会恢复旧皮肤的问题。此前换肤请求只更新内存，只有后续切换主角色或修改其他设置时才可能间接保存；现在每次换肤都会立即将选择写入本地配置。

当前主角色和其他角色的皮肤选择均会保存，连续换肤以最后一次选择为准。昵称、装饰、插画及其他已有设置保持不变；保存继续使用原子文件替换，避免下一次启动读到写了一半的配置。

增加回归检查，覆盖换肤立即保存、连续修改、重新创建游戏状态后恢复皮肤，以及其他设置保留。
