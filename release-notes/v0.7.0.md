## LSPatch 兼容修复与通用架构版

这次更新主要解决 LSPatch 打包后游戏启动闪退，以及进入大厅后 MOD 没有加载的问题。同时新增 Universal 通用安装包，保留体积较小的 ARM64 版，方便在不同架构的手机和模拟器上使用。

### 修复了什么

- 修复 LSPatch 将原始 APK 放入缓存目录后，游戏的 Unity 启动路径检查导致直接退出的问题。兼容处理仍读取原始 APK 的资源，避免更换路径后出现资源位置不匹配。
- 修复首次下载资源、等待登录时间较长时，模块过早结束初始化，导致游戏能进入大厅但没有 MOD 设置的问题。现在会等 IL2CPP 和 ToLua 都加载后再开始初始化 Hook。
- 模块诊断日志会直接使用应用的版本号，便于确认当前实际加载的版本。

### 下载哪个安装包

| 安装包 | 适用环境 |
| --- | --- |
| `MajsoulMax-Hook-0.7.0-arm64-v8a.apk` | ARM64 手机，体积较小 |
| `MajsoulMax-Hook-0.7.0-universal.apk` | 同时包含 ARM64、ARM 32 位、x86 和 x86_64 运行库，适用于对应架构的设备和模拟器 |

通用版为四种架构都包含 Hook、Rust Modder、本地 AI、JNI 和 ONNX 运行库。两个版本的功能、包名和签名一致，可以相互覆盖安装；最低系统要求仍为 Android 10，游戏客户端和注入框架也需要支持实际使用的架构。

### 如何更新

使用 LSPosed 的用户，覆盖安装模块后完全重启游戏即可。使用 LSPatch 嵌入模块的用户，需要用原版游戏 APK 和本次新模块重新打包；只更新手机上独立安装的模块，不会替换游戏包内嵌入的旧模块。已验证的打包组合为 JingMatrix LSPatch 1.2、启用 `--injectdex`、签名兼容级别 `-l 2`。

应用内更新检查已同步到 0.7.0，并在更新元数据中列出两个安装包。

### 验证情况

LSPatch 修复已在 Android 17 ARM64 设备、雀魂 `4.0.16_MC` 上验证：游戏可以正常进入大厅，显示 MOD 载入公告，打开“MOD设置”页面，并成功挂接收发消息。四种架构均已完成编译和运行库完整性、依赖及对齐检查；ARM 32 位和 x86 系列尚未进行真机或模拟器运行验证，对局与助手连接也尚未完成验证。
