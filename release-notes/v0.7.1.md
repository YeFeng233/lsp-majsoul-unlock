# 0.7.1

修复启用本地角色替换后，对局中默认表情和额外表情点击后没有显示的问题。当前安卓客户端用全局表情 ID 发送请求，并在收到服务器广播后显示；服务器以错误码 `2208` 拒绝本地解锁角色的表情时，原先不会触发显示。

新版本保留游戏原本的发送请求和回调，对 `2208` 增加本机显示补偿。这部分仅自己可见，不会改变服务器上的角色或表情拥有记录。正常发送成功的表情继续走原有广播流程；断网、其他错误、房间禁用表情、观战、对局结束或关闭 MOD/解锁表情时不会补偿。过期对局回调不会在新对局显示。

更新模块后请完全重启雀魂，才能加载新版本的表情适配脚本。LSPosed 用户可直接覆盖安装模块；LSPatch 嵌入用户需要重新打包游戏。

增加 Lua 5.1 回归检查，覆盖默认/额外表情、重复回调、原有成功发送、功能开关、对局切换和异常处理。临时诊断版使用的游戏脚本采集代码不包含在正式源码或安装包内。
