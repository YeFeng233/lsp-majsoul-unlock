# 0.11.0 · 独立解锁清单、GitHub 加速与三麻 Mortal

- 解锁数据从 APK 中拆为仓库独立清单。每次管理应用启动时自动对比版本，有新版本则下载并校验，后续补充皮肤无需重新安装 APK。
- 更新页新增本地清单版本、皮肤数量、检查时间和载入状态，并提供手动更新按钮。
- 清单更新在完全重启雀魂后生效，不重置角色、皮肤选择或 MOD 设置。离线、网络失败或校验失败继续使用原有数据。
- 新增 GH-Proxy、LLKK、GHFast、GH-Proxy 备用域名和 iSteed 五个可选 GitHub 加速源，保留自定义 HTTPS 地址作为备选；切换预设不会丢失自定义地址。支持清单、Release 检查和安装包下载，默认直连，应用内加速请求失败时尝试直连。
- 新增“测速并自动选择”：测试所有预设与有效自定义地址，显示清单请求耗时或失败原因，自动启用并保存最快的可用线路。测速不走直连回退，异常网页和过期清单不参与排名；全部失败保留原设置。
- 增加完整文件校验、版本防降级、原子保存和损坏缓存恢复；APK 界面资源更新不会覆盖较新的解锁清单。
- 实验性 Mortal v4 新增三麻模型导入和本地推理，支持 `775×34 → 44` 的兼容 `.onnx`、`.pth` 和 `.pt`，自动保存到三麻配置，保留四麻模型及无人值守设置。三麻红五、拔北和合法动作掩码使用对应的 44 动作协议。
- 提供检查点精简工具，仅移除训练状态并验证推理权重完全一致，原文件保留。模型仍需通过应用内加载和推理校验；四麻仍含部分近似特征，三麻尚未完成长期对局和全量状态评估。
- 根据独立三麻参考对照，修正碰/杠/拔北动作编号及特征顺序、三麻分数截断、宝牌计数、回放立直状态、摸牌前听牌/振听和九种九牌时机。
- 三麻接入本地 Rust SP 算法，补齐进张表、听牌/和牌概率和期望值输入；修正宝牌牌河标记、排名编码、立直后弃牌质量冻结及对手拔北可见牌漏记。相同输入复用计算结果，全部在本机计算。
- 新增 43 个完整参考向量回归；留出集 309/309、公开牌谱片段 70/70、手机专项 43/43 的完整输入和首选推荐均与固定参考一致。这是接入一致性结果，不是实战胜率或推荐正确率，三麻 Mortal 继续保持实验性。范围及限制见[推荐质量验证](https://github.com/YeFeng233/lsp-majsoul-unlock/blob/main/docs/mortal-sanma-quality.md)。

内置清单为 2026.10.24.2，包含 125 个角色、516 套皮肤及其他解锁 ID，已补充本次游戏更新资源。清单维护方式见 `docs/unlock-catalog.md`。
