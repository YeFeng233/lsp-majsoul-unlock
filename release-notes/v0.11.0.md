# 0.11.0 · 独立解锁清单与 GitHub 加速

- 解锁数据从 APK 中拆为仓库独立清单。每次管理应用启动时自动对比版本，有新版本则下载并校验，后续补充皮肤无需重新安装 APK。
- 更新页新增本地清单版本、皮肤数量、检查时间和载入状态，并提供手动更新按钮。
- 清单更新在完全重启雀魂后生效，不重置角色、皮肤选择或 MOD 设置。离线、网络失败或校验失败继续使用原有数据。
- 新增 GH-Proxy、LLKK、GHFast、GH-Proxy 备用域名和 iSteed 五个可选 GitHub 加速源，保留自定义 HTTPS 地址作为备选；切换预设不会丢失自定义地址。支持清单、Release 检查和安装包下载，默认直连，应用内加速请求失败时尝试直连。
- 新增“测速并自动选择”：测试所有预设与有效自定义地址，显示清单请求耗时或失败原因，自动启用并保存最快的可用线路。测速不走直连回退，异常网页和过期清单不参与排名；全部失败保留原设置。
- 增加完整文件校验、版本防降级、原子保存和损坏缓存恢复；APK 界面资源更新不会覆盖较新的解锁清单。

内置清单为 2026.10.23.3，沿用现有 124 个角色、510 套皮肤及其他解锁 ID。本次没有额外查询或猜测新物品 ID。清单维护方式见 `docs/unlock-catalog.md`。
