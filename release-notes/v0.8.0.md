# 0.8.0 更新日志

新增可选的 AI 自动切牌功能。同步实时牌局后，可在助手页或悬浮窗手动开启，根据本地 AI 的首选推荐执行普通切牌；每次启动助手默认关闭。立直、吃碰杠、和牌、拔北和跳过仍需手动，首选为这些动作时不会改用备选切牌。

悬浮窗增加开启、暂停和运行状态显示。启用时收纳浮标显示“停”，点击即可暂停；透明度、宽度和位置调节继续保留。

自动切牌使用游戏原有的手牌选择与出牌流程，执行前核对消息代次、序列、游戏步骤、回合、座位及手牌，并区分普通五与赤五、手切与摸切。只有客户端发送和服务器确认均通过后才继续下一次决策，不自动重试。手动操作、过期推荐、重连、同步异常、模型异常和确认超时会暂停。

助手日志增加自动切牌事件，可检查指令排队、游戏提交、上行确认、服务器接受及暂停原因，并随现有故障 ZIP 导出。

验证覆盖 13 项 Lua 游戏适配保护测试、Android 控制器设备测试和现有 Rust 协议与皮肤持久化回归。在连接手机的四麻机器人练习中，已确认多次切牌提交和服务器接受，以及过期推荐、手动操作和收纳浮标暂停。三麻实际出牌和不同游戏版本仍需进一步验证。
